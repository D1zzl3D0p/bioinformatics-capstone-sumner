# bioinformatics-capstone-sumner

## Dependencies

- conda

## Installation & Usage

```bash
git clone https://github.com/D1zzl3D0p/bioinformatics-capstone-sumner
```

Ensure that the data/00-raws directory (within the repo) is full of your data of
interest

```bash
cd bioinformatics-capstone-sumner &&
./run_pipeline.sh
```
